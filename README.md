# Task 6: Host a Static Website with GitHub Pages

## Objective

Deploy a simple static website using GitHub Pages.

## Project Description

Created a static website using HTML and CSS and deployed it using GitHub Pages. The website demonstrates basic web development and static website hosting.

## Technologies Used

* HTML5
* CSS3
* Git
* GitHub
* GitHub Pages

## Implementation Steps

1. Created the `index.html` file.
2. Designed the webpage using HTML and CSS.
3. Initialized a Git repository.
4. Committed and pushed the project to GitHub.
5. Configured GitHub Pages using the `main` branch and root folder.
6. Verified the published website.
